## Изменения оригинала

В 29 коммитах изменён 81 файл. Основные изменения:

- Исправлены восстановление размеров окна и область перетаскивания заголовка.
- Добавлена навигация по закладкам стрелками и Enter.
- Добавлены пути к закрытым ключам и сертификатам в настройках подключений; исправлена многофакторная SSH-аутентификация.
- Добавлены шифрование данных на стороне клиента для облачной синхронизации и проверка размера отправляемых данных; исправлена работа WebDAV по HTTP.
- Исправлена передача файлов более 2 ГБ через SCP при отсутствии SFTP.
- Добавлена настройка поддержания активности терминала через MCP.
- Исправлены Telnet, отображение фоновых изображений терминала, вкладки и отдельные элементы интерфейса.

## Собственное дополнение

Коммит 01f18bf9 добавляет палитру по Ctrl+Space, её оформление, подключение к горячим клавишам и проверку управления с клавиатуры в тесте Electron. Всего пять файлов, 161 добавленная строка и одна удалённая.

Обновления оригинала не изменяли эти пять файлов. Слияние выполнено без конфликтов. При этом оригинал изменил общий компонент модального окна, используемый палитрой, поэтому проверка её работы в запущенном приложении остаётся необходимой.

## Последующие обновления

Процесс синхронизации создаёт запрос на слияние после проверок. Конфликты останавливают процесс. Русский README и настройки форка следует сохранять при разрешении конфликтов, учитывая актуальные инструкции сборки из оригинала.

Встроенные обновления официальными бинарными сборками отключены параметром `fork.disableUpstreamUpdates` в `package.json`: обновлять нужно исходники форка и затем собирать приложение.
