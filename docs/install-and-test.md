# Установка и проверка сборок форка

## Где скачать

Откройте [выпуски rmtshnik/electerm](https://github.com/rmtshnik/electerm/releases) и выберите предварительный выпуск с названием «тестовые сборки форка». Сборки создаются из коммита, указанного в выпуске, включая палитру Ctrl+Space.

До завершения всех четырёх сборок выпуск не публикуется. Отдельные успешно собранные платформы доступны авторизованным пользователям GitHub в разделе артефактов соответствующего запуска [процесса сборки](https://github.com/rmtshnik/electerm/actions/workflows/fork-build.yml). Артефакт GitHub — дополнительный ZIP-контейнер: сначала распакуйте его, затем используйте лежащий внутри установщик или архив.

## Windows x64

Скачайте файл с окончанием `windows-x64-setup.exe` и запустите установщик. Либо скачайте `win-x64.zip`, распакуйте целиком и запустите `electerm.exe`.

Для изолированных настроек архивной версии создайте папку `electerm` рядом с исполняемым файлом до первого запуска. Папка приложения должна быть доступна для записи.

## macOS

Проверьте процессор в меню Apple → «Об этом Mac». Для Intel нужен файл `mac-x64.dmg`, для Apple Silicon — `mac-arm64.dmg`.

Откройте DMG, перенесите electerm в «Программы» и запустите. Сборка не нотарифицирована Apple. При блокировке после попытки запуска откройте «Системные настройки → Конфиденциальность и безопасность» и разрешите открытие приложения. Не отключайте защиту системы целиком.

Если уже установлен оригинальный electerm, сохраните его настройки и используйте отдельную учётную запись ОС для безопасного сравнения двух сборок.

## Linux x64

Ubuntu/Debian:

```bash
sudo apt install ./electerm-fork-ВЕРСИЯ-linux-x64.deb
```

Либо AppImage:

```bash
chmod +x ./electerm-fork-ВЕРСИЯ-linux-x64.AppImage
./electerm-fork-ВЕРСИЯ-linux-x64.AppImage
```

При отсутствии FUSE можно распаковать AppImage через `--appimage-extract` и запустить `squashfs-root/AppRun`. Поддержка конкретного дистрибутива зависит от системных библиотек. Архив TAR.GZ распакуйте в отдельную папку и запустите файл `electerm` внутри неё.

## Что проверить

1. Приложение запускается и показывает версию выпуска.
2. Локальный терминал открывается, команда `echo FORK_OK` выводит результат.
3. Сохранённые закладки, SSH и передача файлов через SFTP работают.
4. Создайте быструю команду `echo PALETTE_OK` с узнаваемым именем.
5. В терминале нажмите Ctrl+Space, найдите команду по имени, выберите стрелками и выполните через Enter.
6. Esc закрывает палитру и возвращает ввод в терминал.
7. Команда в режиме «только ввод» вставляется без выполнения.
8. Закройте и снова откройте приложение: настройки и команды сохранились.

На macOS Ctrl+Space может быть назначено переключению источника ввода. В этом случае измените сочетание в настройках electerm либо в настройках клавиатуры macOS.

Контрольные суммы опубликованы в `SHA256SUMS.txt` каждого выпуска. Они позволяют проверить целостность скачанных файлов.

## Как выпустить следующую сборку

Процесс «Сборки форка» запускается при изменении кода в `master` и в текущей рабочей ветке `codex/quick-command-keyboard`. После переноса процесса в основную ветку доступен ручной запуск через Actions → «Сборки форка» → Run workflow с выбором ветки.

Успешное завершение всех платформ в основной ветке создаёт новый предварительный выпуск. Рабочие ветки сохраняют файлы в артефактах Actions: встроенному токену GitHub не разрешено публиковать изменения процессов сборки из таких веток. Первый выпуск из рабочей ветки опубликован через авторизованную сессию владельца репозитория.

Автоматической установки обновлений внутри приложения пока нет: скачайте новую сборку из этого репозитория.
