# Переносимая сборка для Windows

Выполняйте команды из корня репозитория на Windows x64 с установленными Node.js 24 и npm:

```powershell
npm ci --ignore-scripts
npm run compile
node src/build/bin/prepare-local-portable.js
npm --prefix work/app install --omit=dev --ignore-scripts
node node_modules/electron-builder/cli.js --config work/local-portable-builder.json --win zip --x64 --publish never
```

Архив ZIP появится в `dist/keyboard-portable`. Распакуйте его целиком в папку с правом записи и запустите `electerm.exe`. Настройки хранятся в папке `electerm` рядом с исполняемым файлом. Команды не публикуют сборку.

Сохраните тестовую быструю команду, например `echo KEYBOARD_OK`, установите фокус в терминале и нажмите Ctrl+Space. Введите часть имени, выберите команду стрелками и нажмите Enter. Esc закрывает палитру и возвращает фокус в терминал. Режим «только ввод» вставляет текст без выполнения. Сочетание клавиш меняется в настройках горячих клавиш.

Встроенное обновление из оригинального проекта отключено для сохранения дополнений форка. После слияния обновлений исходников соберите новый архив. Перед заменой старой сборки сохраните резервную копию папки настроек.
